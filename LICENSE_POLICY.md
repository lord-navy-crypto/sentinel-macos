# Sentinel licensing policy

Sentinel project-owned source code is licensed under the Mozilla Public License 2.0 (MPL-2.0).

- Full license: `LICENSE`
- SPDX identifier: `MPL-2.0`
- New project-owned source files should include `SPDX-License-Identifier: MPL-2.0`.
- Third-party code, if introduced later, must keep its original license and attribution; document it separately rather than relicensing it as Sentinel code.
- The software license does not by itself grant rights to any project trademarks, logos, or branding.

This file is a project policy summary, not a substitute for the MPL-2.0 license text.
