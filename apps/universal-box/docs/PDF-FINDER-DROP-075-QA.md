# Sentinel Box v0.75 · PDF 工作台 Finder 拖放与安全导入

2026-10-22 · 本轮 Draft，基于 PR #99 (v0.74)，尚未进入正式版 DMG。

## 已有能力和这次的缺口

现有 `FileDesk` 已提供合并、拆分、旋转、页面重排、轻量优化、PDF 转图片、预览。合并模式已有拖动**排序**、逐文件移除和真实输出预览，但还不能直接从 Finder 拖入 PDF 来**追加文件**。另一方面，旧版导入函数先清空旧列表和预览，再尝试读取新 PDF；一旦导入坏文件，原有可用工作就会丢失。

## 代码变更

- 在已有 PDF 文件工作台的选择器外加入拖放区域。单文件模式（split/rotate/organize/decorate/convert/compress）拖入一份 PDF 将**替换**当前输入；合并模式拖入的 PDF **追加**到现有列表。通过输入选择器则始终**替换**整个清单，避免混淆。
- 合并追加之前对整个候选列表执行原有 `validateMergeFiles` 限额：最多 20 份、单份 15 MB、合计 60 MB，全部检查真实页数，总计不超过 400 页；不默默忽略超过数量的文件。新文件有效才提交列表和页数。
- 新增的 `importSelectedPdfs` 采用“**先验证，再提交**”机制：坏 PDF、文件太大或数量超限时保留之前选定的 PDF、排列顺序和已经生成的真实合并预览，提示拒绝原因。不修改用户磁盘文件。
- 成功追加、替换 PDF 列表后清除旧预览，避免将之前的文件集合误存为新结果。
- 保持列表内“拖动行来调整顺序”的操作不变，外部 Finder 文件拖入区域与内部排序区域分离，避免误将拖入当作页序指令。
- 单 PDF 模式也可以拖入，且只接受单一可读 PDF；文件过大或无效时保留此前文件。
- 仅处理用户主动选择/拖入的本地文件，不上传、不扫描目录、不增加后台任务、订阅或重复工具目录条目。
