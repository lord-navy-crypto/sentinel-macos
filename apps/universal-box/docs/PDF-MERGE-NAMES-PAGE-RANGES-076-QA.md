# Sentinel Box v0.76 · PDF 合并时核对页面区间及自定义输出文件名

日期：2026-10-22 · Draft，基于 PR #100 (v0.75)，未合并或发布。

## 用户痛点

原有 PDF 合并工作台可以预览、排序、导入不同的 PDF，但始终只保存为 `merged.pdf`，连续几次合并容易分不清哪个是哪个。清单展示每份 PDF 页数，但没有明确告诉用户它会占据合并文件中的哪几页，需要手动累加。

## 实际开发内容

- 每个待合并 PDF 文件旁实时显示合并结果中的**页码区间**（例如“合并后第 1–2 页”“合并后第 3 页”），调整文件顺序、移除或追加文件后立即重新计算。
- 新增“另存为 PDF 文件名”输入框；允许中文和英文；默认与旧版一致为 `merged.pdf`，不改变用户既有工作流。
- 输入 `资料汇总.PDF` 时最终保存成 `资料汇总.pdf`，不会出现重复 `.pdf.pdf` 后缀。
- 在本机阻止路径分隔符、控制字符、系统保留文件名、空文件名与异常过长的文件名，输入错误时显示明确提示并禁止保存。
- **只改文件名不会清除已计算的真实合并 PDF 预览**，不会重新压缩/解码或改变合并内容；合并输入有改变才清除旧预览。
- 保留合并源文件原样，依然使用现有本地 `pdf-lib` 保存 PDF；不上传、不覆盖原文件、不建立重复工具目录。
