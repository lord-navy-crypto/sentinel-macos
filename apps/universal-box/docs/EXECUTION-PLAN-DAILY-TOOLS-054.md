# Sentinel Box · 实用功能实施计划书（2026-10-21）

版本：v0.54 起；依据 [产品总路线图 #62](https://github.com/lord-navy-crypto/sentinel-macos/issues/62) 和 `main` 现有代码核查。**目标不是工具入口数量，而是普通用户完成任务的成功率**。

## 1. 产品原则和取舍

- 保持 **macOS / 免费 / 离线优先 / 不注册 / 明确授权**。默认不联网、不监控剪贴板、不扫描全盘、不覆盖原件。
- **优先修通已有功能的最后一步**：文件选择 → 快捷操作 → 可检查的结果 → 保存 / 复制；不要每次新增一个同义名称和入口。
- 一项功能必须有：实际输入、明确输出、失败反馈、边界保护、用户可理解的限制，以及自动化验证。重要的 macOS 权限和跨应用兼容须实机 QA。
- 仅保留公开文档中的常见功能设计作为参考，不复制第三方界面/代码/素材。

## 3. 本轮 v0.54 交付范围与验收

### A. 截图 / 图片 → Apple Vision OCR → 复制

1. **复用** `VisionWorkflowDesk` 和已有原生 OCR 命令；不复制一个 OCR 引擎或增加重复 catalog entry。
2. 截屏必须用户点击并经过系统画面选择；只提取单帧，立即停止媒体流。原生 OCR 支持时生成可编辑结果；提供明确 **复制识别文字** 按钮。
3. 一键“截图→识别→复制”尽力执行；若 WebView 剪贴板权限失败，文本仍可见并可手动点击复制；**不能说已复制却实际失败**。
4. 浏览器预览不可调用原生 OCR 时必须报告真实限制；仍可截图预览和导入图片。Mac 系统权限、语言模型和真实识别质量属于待实测项。
5. **自动测试**：纯粹的识别文本整理辅助测试、Browser 禁止假 OCR、现有截图/mock 路径回归和下载路径。

### B. PDF 结构优化 / 前后对比

1. 用户手动选择 100 B–15 MB 的 PDF，仅对本机文件尝试 `pdf-lib` 重新封装（Object Streams）。**这是谨慎结构优化，不是图片分辨率重压缩，也不保证缩小**。
2. 显示源文件大小、候选大小、节省百分比与页数。只提供比原件真的更小时的保存动作；失败或变大则明示“无优化收益”，不制造虚假压缩率。
3. 读取/重存可能影响数字签名、PDF/A 合规或高级交互字段：对签名及特殊文档给出显著警告，禁止声称“无损保留所有高级功能”。不解锁受密码保护的 PDF，不执行外链。
4. 单元测试真实 PDF：重存前后页数与可见文本标记 / PDF 结构一致，含非优化情形；Browser 上传真实文件并回读产物。
5. 扫描件图片重压缩与搜索型 PDF OCR **后续单独任务**：必须设计质量滑块、渲染预览、保留原件且检验文字层，未实现前不宣称覆盖。

## 4. 实施顺序

- **v0.54（本轮）**：路线图落仓 → 实用 PDF 结构优化 → 截图/OCR/复制链路 → 单测/Chromium/Intel/ARM CI → 文档中记录缺陷。
- **v0.55**：扫描件 PDF 图片压缩（DPI/JPEG 质量分档、前后预览），无效优化须提示、可选不另存。
- **v0.56**：高频图片 HEIC / JPEG 互转与逐张大小报告；优化批量操作 UI。
- **v0.57**：可访问启动器、统一搜索、快捷键、无后台剪贴板默认权限。
- **发布验收专项**：真实 Intel/ARM Mac 的截屏授权、Apple Vision 中英文 OCR、跨软件复制、真实 Word/Preview PDF 样本对照；两台 Mac LAN 手工验证；签名、公证和软件更新。

## 5. 官方基准与产品定位

- Apple macOS 预览：Live Text 从图片选择、复制文字 <https://support.apple.com/en-gb/guide/preview/prvw625a5b2c/11.0/mac/27>
- PDF24 PDF 压缩：DPI、图片质量和压缩模式 <https://tools.pdf24.org/en/compress-pdf>
- PDF24 Creator（**仅 Windows，非 Mac 本机**）：<https://tools.pdf24.org/en/creator>
- Sentinel Box GitHub 需求总表：issue #62。重要区别：PDF24 在线工具涉及云服务，而 Sentinel Box 的主要卖点是 **本机和透明处理**。

## 6. 合格标准

- 不把“工具入口可点击”算完成。必须证明结果真实可读；预览 / 下载内容一致。
- `npm run build`、`npm test`、Chromium真实操作、macOS双架构构建分别标注 **通过 / 失败 / 未运行**。
- 未合并 PR 和实机验证不能写为已发布功能；安全、隐私和文件格式限制必须清楚。
