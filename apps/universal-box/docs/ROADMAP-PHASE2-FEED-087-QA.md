# Sentinel Box 终极计划 · v0.87 离线 RSS/Atom 订阅档案

日期：2026-10-22。仅为开发 Draft，不是已发布应用版本。

## 计划依据及边界

遵循在开发之前归档的计划：`apps/universal-box/docs/archive/SENTINEL-BOX-ULTIMATE-PLAN-2026-10-22.md`，P1-2 机会项“本地 RSS/Atom 离线导出文件整理”。与已有书签 HTML 整理不同：这里按 RSS 2.0 的 channel/item 或 Atom 1.0 的 feed/entry **XML 文档结构**读取真实条目、发布日期与来源元数据。

这是处理用户已经保存的 XML 文档的静态归档工具，**不是**在线新闻客户端、抓取器、网页阅读器或自动订阅服务。无需新依赖、账户、订阅、网络连接、后台刷新或平台权限。

## 功能

1. 用户手动选择一个 UTF-8 的 `.rss`、`.atom` 或 `.xml` 文件（≤2 MB）。使用浏览器内置 XML DOMParser 解析，不把 XML/HTML 注入实际页面或作为 HTML 渲染。
2. 只接受 RSS 2.0 / Atom 1.0 常见 XML；拒绝 malformed XML、DTD、ENTITY、XML stylesheet、超过 1,000 个条目的文档。
3. 提取标题、HTTP(S) 网址、站点域名、发布日期、部分摘要（最长 350 字符），保留文件中原始条目顺序。拒绝本地 file:/javascript:/data:、非绝对或嵌入身份验证信息的网址；不访问任何网址，也不显示从源站加载的图片。
4. 展示条目总数、重复完整 URL、跳过的条目和常见域名。用户可以筛选屏幕标题、域名和摘要；只显示前 80 条，但导出**总是完整的**有效条目集合。
5. 导出 UTF-8 BOM CSV（公式注入防护、引号转义）或 Markdown 链接清单；可选勾选仅在导出时按完整 URL 去重，默认保留全部，不修改原始 XML。
6. 新 XML 导入失败时保留此前成功的档案和去重选择；清空只释放此窗口数据。
7. XML 可能包含私人订阅信息，下载后请自行检查、存储和分享。
