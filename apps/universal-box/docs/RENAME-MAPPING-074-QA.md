# Sentinel Box v0.74 · 批量重命名对照清单

2026-10-22 · 开发版 Draft，依赖 PR #98。开发代号不等于已发布的安装包版本。

## 用户场景

批量重命名可以生成文件和预览，但之后需要知道 **原名对应哪个新名**：整理照片、收据、研究资料或提交文件时尤其常见。此前原始文件名导出不含新名，ZIP 中也缺少完整对照清单。用户不得不回到软件界面手工核对。

## 本轮代码

- 复用现有 EverydayTools 的安全重命名规则、ZIP 输出以及数据校验，不新增重复工作台。
- 新增“单独导出原名→新名 CSV 清单”，无需实际重命名就能先核对计划。
- 每一个重命名 ZIP 自动包含 `reports/rename-map.csv` 和 `reports/rename-manifest.json`。内容按用户实际选择顺序记录索引、原始名称、新名称、原始字节大小；不包含文件内容或私密绝对路径。
- CSV 添加 UTF-8 BOM 方便常见表格软件识别中文，双引号和逗号按 RFC 风格转义；以 =、+、-、@ 等字符开头的 CSV 字段前加单引号，降低表格公式注入风险。JSON 保留原始完整名称，不添加修改用前缀。
- 原始文件不会更名或覆盖。每个 ZIP 包中的文件仍以校验过的目标名称保存，重名冲突时整个导出会拒绝。
