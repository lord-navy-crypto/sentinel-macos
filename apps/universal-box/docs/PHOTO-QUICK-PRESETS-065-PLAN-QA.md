# Sentinel Box v0.65 · 照片一键预设与单张直出（Draft）

2026-10-22 · 建立在 PR #89 的多段复制改进分支之上。不是正式发布。

## 具体痛点

原有照片压缩器可通过 Canvas 本机编码真实 JPEG/WebP、验证压缩字节数、预览和打包 ZIP；但只有**一张**图片时也下载 ZIP，用户为了上传头像或发附件必须先解压。现有格式、最长边与目标 KB 是三个分别设置的控件，不够适合一次性的普通操作。

## 本轮新增

- **邮件附件**：1024 px / JPEG / 250 KB 目标。
- **网页上传**：1024 px / WebP / 400 KB 目标。
- **保留更多细节**：2048 px / JPEG / 1500 KB 目标。
- 每一个预设只是本地原有算法的参数快捷输入，绝不声称可以保证目标大小，也不新增商业或云端服务。仍可人工修改参数。
- 1 张照片：复用现有已处理的 ZIP 内的图片编码结果，从中验证实际文件字节数并直接保存 JPEG 或 WebP，不再要求用户解压。
- 2–10 张照片：继续导出带 manifest.json 的 ZIP，保持既有体积审核信息。
- 在处理期间禁用照片选择和参数修改，防止“用户参数已变但旧结果仍显示”的交互问题；任何预设变更必须清除旧预览与已准备导出结果。
- 原始图像不会覆盖；HEIC 仍严格限制在支持本机解码的 macOS App，不伪装为浏览器功能。

## 范围界限

不添加复杂商业工作台、不付费、无云端上传、不批量超大文件、不保证压缩率、不会静默移除已有工具功能。建议之后对 PDF 合并等已有能力同样优化“单文件直接输出、拖拽导入、清晰的失败提示”。
