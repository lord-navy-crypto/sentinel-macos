# Sentinel Box v0.69 · 离线图片 OCR 一键复制与可选折行预览（Draft）

日期：2026-10-22。基于 PR #93（v0.68）；开发里程碑，不等于正式版本或 macOS 已部署。

## 已有能力、真实缺口

现有 VisionWorkflowDesk 已有 Apple Vision 离线图片 OCR、对已识别文本复制、TXT/DOCX 导出以及“一键截屏→本机 OCR→复制”流程。无需重新开发识字引擎。**缺口**是已有图片选择后，要先点“识别”，再等结果、点“复制”；且对 OCR 多余换行的处理需要转到另一文字工具，没有不破坏原文的预览。

## 本轮实际代码

- 新增 **「导入图片 → 本机识字 → 复制原文」** 按钮，复用原有的 `recognizePhoto(file,true)`。只在用户主动点击、已选择图片且 macOS Tauri 原生 OCR 可用时启用；浏览器不伪造识别结果，不调用云端识字 API。剪贴板权限失败时仍可在页面核对、手动复制原文。
- 原有“截图→本机识字→复制”和“识别→人工校正→复制/TXT/Word”不删除、不重写。
- 每次导入或重新识别时清除旧 OCR 编辑结果、折行预览，避免上一次图片的结果误留在新图片上。识别期间禁止换图。
- 提示 Apple Vision 识别结果中 **置信度低于 0.65 且非空** 的行数；仅用于人工复核优先级，不能等同实际正确率。
- 新增 **默认关闭** 的折行整理选项：用户勾选后，复用现有 QuickKit 的意外折行启发式算法，显示**只读结果**；另外提供「复制整理预览」及「另存整理 TXT」。原始 OCR 文本以及用户手动校正框不覆盖、不自动改写；误合并标题、代码、诗歌仍可能发生。
- 所有处理离线，仍限制图片 ≤8MB，识别文字 ≤200,000 字符，没有剪贴板后台监听或永久识字历史。
