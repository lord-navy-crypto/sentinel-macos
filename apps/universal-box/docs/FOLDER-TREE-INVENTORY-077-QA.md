# Sentinel Box v0.77 · 免费本地文件夹目录树与清单

日期：2026-10-22；开发 Draft 基于 PR #101，尚未合并或发布。**这是一项新类别功能，不属于 PDF、压缩图片、OCR、重命名或语音。**

## 用户需要什么

快速说明项目文件夹有哪些目录和文件；向团队分享目录结构；查找占空间的文件格式，或者记录文件夹整理前的目录结构。原有 SHA-256 查重/文件检查工具主要检查具体文件内容或签名，不会生成真实目录树。

## 实际实现

- 从浏览器或 macOS WebView 支持的 **文件夹选择器** 读取浏览器赋予的 `webkitRelativePath`、文件名、字节数、最后修改时间；多选文件选择器作为不支持目录选择时的降级（降级时不猜测目录路径）。
- 最多 1,000 个文件、25 层目录，拒绝非法/重名路径、绝对/遍历路径和不合理的文件大小、时间戳；不截断文件数量。错误导入不会覆盖此前的有效清单。
- 预览完整 Markdown 目录树（包括父文件夹）、总文件数、子文件夹数、总字节数和按真实字节统计的扩展名分布。
- 支持文件名/相对路径搜索；只影响最多 100 个可见文件行，导出的 CSV / Markdown 始终包含全量已选文件。
- CSV 有 UTF-8 BOM、标准引号转义、危险公式前缀保护，含相对路径、文件名、扩展名、字节数及 UTC 修改时间。
- 所有数据处理仅靠 File 元数据和纯 TypeScript：**从不调用 `arrayBuffer` 或读取选中文件内容、从不遍历绝对路径、从不上传**。不会主动删除/改名/复制原始文件。
- macOS WebView 对 `webkitdirectory` 支持可能存在差异；不承诺所有 macOS 版本可选文件夹。保留多选文件回退方案。
