# Sentinel Box v0.67 · 日常 PDF 合并排序、检查和真实预览

日期：2026-10-22 · Draft；本开发分支基于 PR #91，尚未进入稳定版。

## 实际用户问题

原有 FileDesk 的 PDF Merge 接收一组 PDF，直接按照操作系统文件选择顺序合并，无法在保存前改顺序、移除选错文件或检查每份文件页数。对于资料合并，文件页序比增加一个新 PDF 工作台更重要。

## 本轮实际修改

- 保留 **FileDesk 原有 PDF Merge**，不增加工具目录条目，不改变其他 PDF、图片、Word 模式。
- 一次选择 1–20 份本地 PDF；导入时顺序检查每份 PDF 的真实页数，不读取文件名猜页数；错误会说明是第几份。只允许单份 100 字节至 15 MB、全部 ≤60 MB、合计 ≤400 页；输出不超过已有导出功能的 20 MB 限制。拒绝超过限制，不默默丢弃第 21 份文件。
- 文件行显示序号、文件名、页数、原始字节数。支持拖放排序和明确的上下移动按钮、逐行移除以及清空。相同文件名允许出现多次，不按名字去重。
- 「生成真实合并预览」在内存产生实际 PDF，并复用已有的 PDF 缩略图、翻页预览。修改顺序、删除文件或重新导入会使旧预览失效，避免导出旧顺序。
- 「按当前顺序合并并另存 PDF」如已有预览则复用同一份输出字节，否则即时生成。全部离线处理，原始 PDF 不覆盖，不自动打开嵌入的 URL。
- 复杂 PDF 的文档级签名、表单与目录在页面复制后可能变化，正式对外分享前要核对。
