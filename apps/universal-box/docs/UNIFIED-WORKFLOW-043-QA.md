# Sentinel Box · Unified Workflow v0.43 Candidate

## What this release actually integrates

The new **Unified Workflow** tab in the existing Workflow Studio accepts **1–16 explicitly selected local files**, at most **8 MB each, 16 MB total**. It previews a per-file conversion plan, then executes trusted existing local modules and combines results into one portable ZIP.

| Input | Operation | Actual output |
| --- | --- | --- |
| TXT / Markdown | Existing `markdownToDocx` | Editable Word `.docx` |
| CSV | Existing `cleanWorkspaceCsv` | Cleaned `.clean.csv` with formula-cell escaping |
| JSON | Existing `auditJsonToTypescript` | `.ts` structural types + `.paths.tsv` audit |
| DOCX / PPTX | Existing bounded `inspectOffice` | Read-only extracted `.extracted.txt` |
| PNG / JPEG / WebP | Existing `imageWorkflowScale` + canvas | Re-encoded `.png`, max dimension 512/1024/2048 |
| Other (e.g., PDF/WAV) | **No invented conversion** | Only optional copy of explicitly selected original |

**Every ZIP** includes `reports/manifest.json` and `reports/README.txt`. Manifest lists the SHA-256 digest of each original, exact processing step, output names, successes, skips, and failures. Conversion errors are isolated by input: one bad JSON file cannot erase a good Word/PPT output. Unrecognized files do not execute or get falsely marked converted.

**Privacy & source safety:** Explicit file selection only. No disk crawling, accounts, server calls, overwrite, automatic deletion or embedded macro execution. Copying originals is opt-in and clearly flagged. ZIP output limited to 20 MB. Generated office text does **not** preserve original layouts, screenshots, videos, formulas, images, or accessibility tags.

## Real tests

- Vitest: generate genuine editable DOCX + PPTX with existing generators, feed them back into the mixed workflow alongside CSV, JSON, Markdown and a signed PNG, inspect every ZIP member, generated type source, formula escaping, notes, source SHA-256 and the JSON audit.
- Failure tests: invalid JSON, file extension/signature disagreement, safe names for user-provided path-like strings, opt-in original copies, unsupported PDF, and byte/file-count bounds.
- Chromium: user uploads actual Word (generated by `docx`), Markdown, CSV, JSON and browser-drawn PNG together; downloads the resulting ZIP; reopens embedded DOCX, validates CSV/TypeScript/Office text, decodes the converted PNG to inspect dimensions and color pixels.
- Chromium separate failure test verifies errors in manifest and user-original preservation, with all previous 121 discovery entries also included in navigation tests (now 124).
- Native Intel / Apple Silicon Tauri + Sentinel core regressions must pass before merge. Real macOS app and Office layout compatibility remain separate manual checks.

## Product design rationale

Treat this as a **single auditable local workflow engine**, not a new set of buttons pretending to be full Word/PPT/PDF editing. It reuses existing tested modules and adds safe multi-input composition, preflight, per-file status and consolidated outputs. Future iterations can extend individual adapters (OCR, PDF, video) only once the underlying native operation is proven and consent-safe.

The package name, macOS product title and user-facing release name are **Sentinel Box**; legacy `apps/universal-box/` source path and persisted identifiers remain intentionally unchanged for backward compatibility.
