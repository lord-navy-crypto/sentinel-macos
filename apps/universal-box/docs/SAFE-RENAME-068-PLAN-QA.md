# Sentinel Box v0.68 · 批量重命名安全预览（Draft）

日期：2026-10-22；基于 PR #92（PDF 合并预览），未进入稳定版。

## 真实缺口

既有 EverydayTools 的 Batch Rename Copies 在导出 ZIP 时才检查重名，先直接截断生成的新文件名到 130 字符，长文件名可能连扩展名也被截断；选择超过 50 个文件时直接截取前 50 个，可能令用户误以为全部文件都已处理。

## 本轮修复

- 复用现有批量重命名界面、原有文件名清单 TXT/CSV 和 ZIP 导出，**不增加额外工具或订阅**。
- 新增单独可测试的计划模块 `safeRenamePreview.ts`：先验证最多 50 个、原始文件总计 ≤16 MB，再根据 Prefix、查找/替换、起始序号计算新名字。
- 先为扩展名和序号预留长度，再裁剪基础名称，确保无论原文件名多长都不会默默丢失 `.pdf/.jpg/.docx` 等扩展名。
- 过滤路径分隔符和控制字符，移除开头无意义点号，NFC Unicode 归一化，进行不区分大小写的目标文件名冲突检查（只是预防性措施，不能保证所有外部文件系统兼容）。
- 导出前提供明确的原名→新名预览和验证结果；不合法配置会显示错误并禁用 ZIP/逐文件导出。
- 超过 50 个选择不再悄悄截断；清空选择并告知用户。
- 源文件字节不修改，始终保存新副本；离线运行，不上传文件。
