# Sentinel Box — Typography and Safe File Conversion QA

**Scope:** PR #119, independent of Draft #118 and #120. No automatically published or notarized release is claimed.

## Actual conversion routes in this tool

| Input | Output | Result | Known loss or restriction |
| --- | --- | --- | --- |
| UTF-8 TXT | DOCX | Editable text, chosen font/size/weight/style/alignment | Original document styling does not exist in TXT; font substitution possible |
| UTF-8 TXT | standalone HTML | Escaped user text with offline CSS styling | Browser font fallback/layout may differ |
| UTF-8 TXT | UTF-8 TXT | Literal text; optional opt-in symbol approximations | TXT cannot store font size, color, weight or alignment |
| UTF-8 MD | DOCX/HTML/TXT | **Literal source**, not rendered Markdown | Markdown markup remains characters; use the existing Writing workbench for Markdown-aware formatting |
| HTML generated by this feature | DOCX/TXT/HTML | Safely extracts its escaped `<main>` text **without parsing or executing HTML** | Original imported HTML layout is deliberately discarded; user explicitly chooses new styles |
| Arbitrary internet HTML / HTM | — | Rejected | No script, network, image or CSS processing from untrusted webpages |
| RTF, DOC, ODT, PDF | — | Unsupported in this desk | Do not relabel extensions or claim layout fidelity |
| Clipboard styled copy | HTML + plain text | Explicit user-triggered `ClipboardItem` copy | May be unavailable due to OS/browser permissions; plain copy and exported files remain |

## Existing tools that should be reused rather than duplicated

- Main File Workbench supports image resize/convert for JPEG, PNG and WebP; Draft #120 adds real image signature checks, output validation and an explicit no-animation guard.
- Free Formats has basic XLSX ↔ CSV and JSON values with limited formula, styling and sheet support; conversion is not a full spreadsheet roundtrip.
- PDF desk includes selected PDF page/image workflows; exporting images and reconstructing a PDF is not lossless.
- Apple native Vision OCR needs an authorized macOS environment. A browser test cannot invent a successful OCR transcript.
- Existing portable text conversion handles Windows/macOS line-ending and text encoding formats; this typography desk intentionally requires UTF-8.

## Compatibility / risk disclosures

1. **Fonts:** a font name saved in DOCX/HTML is a request, not a guarantee of installation on the receiver's system. Size is recorded in pt; DOCX run-size values are expressed in half-points.
2. **Lossy symbol conversion:** math symbols, typographic quotation marks, bullets and symbols are only approximated when the explicit switch is enabled. Users review the output before exporting.
3. **HTML security:** user content is always HTML-escaped on output; importing only accepts the exact, locally defined Sentinel Box template and escaped content. No arbitrary HTML-to-Word fidelity promise.
4. **Rich clipboard:** clipboard access is write-on-click only, never monitored. A plain-text fallback is provided in the clipboard item. Permission errors are shown clearly.
5. **Limits:** 100,000 UTF-16 code units, 3,000 lines, strict UTF-8 imports, TXT/MD size <=250 KB, own HTML <=450 KB, DOCX output <=8 MB.
