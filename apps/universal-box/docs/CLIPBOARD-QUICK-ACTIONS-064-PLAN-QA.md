# Sentinel Box v0.64 · 高频多段复制改进（Draft）
日期：2026-10-22

## 实际改进
当前 QuickKit 已有 Multi-copy 入口，本轮**不增加重复工具和工作台**，只补齐：
1. 在用户**主动点击**时读取当前剪贴板纯文本，并收集到**当前会话**（最多 30 段、总长 100,000 字符、单段 20,000 字符）。系统拒绝读取时提供手动粘贴回退。
2. 每段均可上移/下移/移除，不改变片段原文；可一键清空。
3. 明确区分「复制合并纯文本」与「保存本地 TXT」。三种原有片段分隔符保留。
4. 修正原先 `addClip` 无条件 `.trim()` 的内容损失：现在仅用 `trim()` 判空，实际内容原样保存（包括有意义的缩进、前后空格和换行）。
5. 不新增账号、订阅、云端上传、后台轮询、永久剪贴板历史记录，不持久化片段。
