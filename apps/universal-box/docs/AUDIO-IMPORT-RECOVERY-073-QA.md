# Sentinel Box v0.73 · 本机音频拖入与失败恢复

2026-10-22 · 依赖 PR #97，Draft；只是开发里程碑，并非已经发布的安装包。

## 为什么开发

现有录音、导入 WAV/MP3/M4A、本机 Apple Speech 转写和字幕导出已可使用。实际不足：只能通过选择框导入音频；重新选择不兼容的文件后，之前成功解码的音频和转写可能被清空；没有直接清空当前会话的按钮。

## 本轮完成

- 在现有 SpeechPortableDesk 中新增单音频拖放区（可从 Finder 拖入），保留原文件选择器。不启动隐藏麦克风、无背景扫描、不上传任何音频。
- `validateAudioImport` 先拒绝未知扩展名、短于 44 bytes 或超出 12 MB 的文件。扩展名只是初步筛选，真正的格式仍由当前 WebView 的本地解码器检查；不会承诺所有系统都支持 FLAC/CAF 等编码。
- 只有成功解码为 PCM16、16kHz、最长 90 秒时才替换旧音频并清空对应的旧转写。解码失败时保留此前成功音频和转写，避免因为格式问题丢失工作。
- 可以明确点击「清空当前音频与转写」，不会删除磁盘文件；录音/解码期间不允许修改会话。
- 浏览器仅能本地解码、导出 WAV，Apple Speech 转写仍仅用于支持离线识别的 Mac 桌面系统，不伪造识别内容和时间戳。
- 保留旧的 WAV/DOCX/TXT/SRT/WebVTT 导出能力；不新建重复工作台。
