# Sentinel Box v0.66 — PDF 快捷操作与拖入导入（Draft）

2026-10-22 · stacked on PR #90 (v0.65)；仍是开发分支，不是最终安装版本。

## 用户问题

原有 PDF Mini Editor 已有体积优化、提取页面、裁边、插入空白页等功能，但用户需要先选择正确标签，再手写页码表达式。文件只能通过选择按钮导入，拖入 PDF 不能直接打开。

## 本轮交付

- 在**现有** PDF Mini Editor 页面加入单文件拖入区；仍复用 `inspectPdfEveryday`，限制 15 MB 和最多 200 页，不读取整个目录、不上传、不覆盖原件。
- 导入后展示常用按钮：压缩 PDF、提取首页、提取末页、仅奇数页、仅偶数页、倒序页面。
- 快捷按钮仅**填写提取表达式并切换到现有编辑面板**；用户必须检查表达式，再点击另存，避免误导为自动保存。
- 新增「先预览所选页面」：直接生成真正的 PDF 工作副本，展示可翻页预览；用户确认后复用已经准备好的字节导出。修改表达式、导入新 PDF 或更换快捷任务，会清除旧预览。
- 复用已有的 `parsePdfPageOrder` / `exportSelectedPdfPages`，不新增重复 PDF 引擎；整份 PDF 的倒序最多 200 页，其表达式允许 900 字符。
- 正在处理和存在未保存链接修改时不允许通过快捷按钮进入其他 PDF 操作；防止把尚未保存的中间结果误认为原件。
- 原来的压缩算法仍区分结构优化与仅扫描图像重编码；不承诺任意 PDF 一定能缩小。
- **不声称**页面提取会保留所有 PDF 书签、交互表单、数字签名等高级文档级结构。
