# Sentinel Box 终极开发计划 · v0.86 文件夹快照差异比较

日期：2026-10-22 · 开发 Draft（不是已安装发布版本）

## 来源、区别及实现

归档基线：apps/universal-box/docs/archive/SENTINEL-BOX-ULTIMATE-PLAN-2026-10-22.md（先于代码提交，基线 commit 2855a335）。

前置：PR #108 经典 HEX/EML、#109 多文件只读文本搜索。优先修复前两批浏览器 CI 暴露出的导航登记错误（App.tsx 旧逻辑只允许侧边栏菜单视图，忽略已在 LOCAL_TOOLS 登记的独立工作台）。新导航仅允许已经登记的本地工具 ID/View，不接受任意字符串。

本功能与现有文件夹目录清单、单文件 Binary Compare、SHA-256 重复文件检查均不同：对**两次用户明确选择的目录**按相对路径和元数据进行差异比较，不主动读取文件内容。

1. 选择旧快照和新快照：File picker 支持 webkitdirectory 时保留相对层级，最多各 1,000 文件；多选文件作为浏览器不支持文件夹选择时的退化路径，退化后不能无中生有猜测路径。
2. 各目录的第一个公共根文件夹名称可不同；仅当每条路径都含这个公共根前缀时移除其标签。子文件夹层级保持不变。路径大小写精确区分。
3. 四种变化：新增、删除、文件大小/修改时间变化、元数据相同。每条记录均给出原相对路径、理由、旧/新字节数和 UTC 修改时间。
4. 默认只显示变化，亦可包括未变化；仅前 100 条渲染，但 CSV 保存当前过滤条件下的**所有**记录（上限 2,000）。
5. 错误导入保留以前的成功快照和报告，清空只清除当前视图，不修改文件系统中的任何文件。
6. CSV 使用 UTF-8 BOM、标准引号转义、危险 Excel 公式单元格防护。用户主动点击导出才写新文件。

## 必须透明说明的局限

- **元数据相同不能证明内容相同**。改动文件内容但保持大小和修改时间，会被报告为“元数据相同”。复制文件使修改时间变化，但内容未变，也会被报告为“元数据变化”。
- 不读取、哈希、复制、改名、删除任何源文件字节；不自动递归扫描全盘、不联网、不索取额外权限。不支持隐式空文件夹：普通浏览器目录选择器不会报告没有文件的空目录。
- 真实 macOS WKWebView 对 webkitdirectory 兼容程度须实机验证；保留多选文件退化方案。
- 仅作“可能发生变化的文件”清单，不可代替备份一致性、代码审计或内容校验。

## 维护纪律

本功能与其他新功能继续使用已存在的 ToolLaunchpad 和 App 路由，不加入新第三方库、不长期持有文件句柄、不修改原始文件。真实 CI、失败回归及实机验证优先于扩张工具数量。若 CI 出现失败，优先修复本功能、旧功能测试或导航问题。
