## 目标与区别

- HEX Viewer：不重复二进制比较热力图或文件类型识别。展示一份文件真实字节、偏移和 ASCII，512 bytes/page、16 bytes/row，精确字节模式搜索和摘要导出。源文件只读。
- EML Viewer：不连接在线邮箱或新做邮件客户端。用户选择本机 EML，解码有限范围的 MIME 纯文本、主题与附件元数据；不渲染 HTML、脚本和远程跟踪图片。
- 完全离线，不增加订阅、账号、遥测、文件夹自动扫描、持久监听或权限绕过。

## 安全约束

1. HEX 最多 8 MB，每页仅渲染 512 bytes；空文件或超限时保留之前的预览。
2. EML 输入 ≤2 MB、邮件头 ≤32 KB、MIME 部件 ≤40、嵌套层级 ≤4、正文显示 ≤100,000 字符；附件只做元数据记录，不执行/预览附件。
3. EML 仅覆盖常见 RFC822/MIME 的受限子集，复杂签名、密文和所有字符集的完美兼容不属于首版。
4. 摘要文件仅用户明确点击后保存，无后台写入。邮件可能含敏感信息，导出后应由用户自行妥善保管。
5. 用户文件展示只通过纯文本控件，拒绝动态执行 HTML 或联网访问远程资源。
