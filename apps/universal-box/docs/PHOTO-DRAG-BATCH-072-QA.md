# Sentinel Box v0.72 · 照片拖入追加与批量清单管理

日期：2026-10-22；Draft，基于 PR #96。不是正式版安装包。

## 背景和目标

现有 Target Size Photo Compression 已能单图直接 JPG/WebP 另存、2–10 张输出 ZIP、显示真实压缩字节数、提供邮件/网页/细节预设。但更换输入需要重复打开文件选择器，用户也无法从已选的多个文件中单独移除一张。旧预览在变更照片清单后必须失效，避免错发文件。

## 本轮交付

- 在**现有**照片压缩面板加入 Finder / 浏览器图片拖放区：拖入的图片**追加**到当前选择；使用文件选择器则替换当前选择。
- 拖入之前调用既有 `planPhotoBatch` 检验数量、格式及文件大小：PNG、JPG、JPEG、WebP、HEIC/HEIF，最多 10 张，单张 ≤8MB、合计 ≤25MB。不满足时拒绝追加并保留已有清单。
- 在照片清单逐条显示序号、原始文件名和大小，新增单独移除、清空全部。允许多个图片名称相同但实际输入不同，输出仍依既有顺序编号。
- 成功添加、移除或清空图片时立即清除上次压缩报告、实际图片预览及可复用 ZIP。导出时只能使用当前所选内容。
- 处理期间禁止修改清单，原始图片不会覆盖；拖入文件也不自动上传或开始压缩。
- 浏览器版仍不伪造 HEIC 解码，只有支持的 macOS 本机解码功能才可用。
- 不建立新的工具入口、不增加任何网络或订阅费用。
