# Sentinel Box v0.71 · 剪贴板权限回退与本地文本导入（Draft）

日期：2026-10-22；基于 PR #95。此 PR 为堆叠开发分支，不代表已发布或能马上下载最新版 DMG。

## 真实问题

QuickKit 已具备明确点击后才访问剪贴板的纯文本读取、文本清理、片段合并和 TXT 导出，但系统 WebView/浏览器可能拒绝剪贴板读取与写入，原有提示要求用户自行找输入框、选中文字。另一个常见需求是直接对本地 TXT、Markdown 或字幕文件运行现有清理功能，无需用外部编辑器打开再复制粘贴。

## 本轮修改

- 加入清晰、可点击的 **「选中原文，手动复制」「选中全部结果，手动复制」「选中合并结果，手动复制」**。这些按钮会将相应文本框聚焦并全选；用户按 ⌘C（Windows/Linux Ctrl+C）即可完成复制，无需调用剪贴板 API。
- 在自动复制遇到权限异常时，自动选中正确的原文/处理结果/合并结果，并提示快捷键；不声称后台自动复制成功。剪贴板读取失败时保持当前编辑文本不变，用户始终能通过常规粘贴继续。
- 新增文本文件选择与拖放区，复用现有 QuickKit 处理算法，支持 TXT/TEXT、MD/MARKDOWN、CSV/TSV、LOG、JSON、SRT/VTT、INI 的 **UTF-8** 文本。单份 1–200,000 bytes、编辑器最多 200,000 UTF-16 字符；使用严格 UTF-8 解码，拒绝二进制 NUL 和不受支持的格式，保留原文缩进/换行。
- 只有用户主动选择或拖入时才读文件。解码失败不会覆盖编辑框；不做文件夹扫描、不联网、不监测剪贴板、原始文件不变。
- 文件编码不合适时，提示现有的 Windows↔macOS 编码转换工具，避免乱码后继续清理。
- 无新增工作台和目录条目，所有代码加入现有 QuickKit。
