# Sentinel Box v0.50 — bookmarks, ICS calendars, and subtitle QA

This release adds three independent offline-first tools without making existing EPUB/SHA-256/CSV workflows redundant.

## Capabilities
1. **Bookmark HTML import**: choose a browser-exported Netscape-style HTML file (up to 1 MB); decode titles and URLs; reject anything except HTTP(S) URLs without embedded credentials; deduplicate matching fully-qualified URLs; download formula-safe CSV or simple Markdown. No HTML scripts run, no link navigation performed.
2. **ICS Calendar Import and Overlap Audit**: parse an uploaded UTF-8 ICS (up to 500 KB; 200 VEVENT records) with strict UTC DTSTART/DTEND including seconds and Z suffix, unfolded RFC5545 continuation lines, plain summary and location, and time overlaps. Export formula-safe CSV. Reject unsupported timezone-dependent, all-day, and recurring events instead of silently shifting times or omitting recurrences. No calendar API access or invitation sending.
3. **Subtitle Timeline QA**: analyze 1–1,000 cues of SRT / WebVTT from the existing validated subtitle parser, identify adjacent overlaps, out-of-order timestamps, gaps, too-short/long durations and high characters-per-second (a heuristic not a comprehension score). Export CSV or JSON without modifying the original subtitles.

## Safety and limitations
All source files are opt-in. Nothing scans folders, reads ambient browser history or clipboard, transmits URLs, subscribes to a service or overwrites files. Imported bookmark URLs and calendar contents may be personally sensitive. Preserve originals and review exported reports before sharing. Generic HTML pages are **not** promised to parse as bookmark exports. Recurring calendar rules, custom VTIMEZONE, floating times and all-day events are deliberately unsupported. Subtitles with advanced WebVTT positioning tags are rejected by the existing strict parser.
