Security Posture

Explicit capture

System Snapshot & Diff

Captures selected current processes, launch services, TCP state, mounts/filesystems, and core security posture. Retention is bounded; it is not a complete audit log.

Growth + bounded age evidence

Storage History & Aging

History captures completed Storage Intelligence results explicitly. Aging uses modification timestamps only for the bounded large-file set retained by the latest scan; it is not a complete inventory of every file.

Recovery Center 2.0

Aggregates Sentinel-owned Safe Actions, Vault, action journal, Change Monitor checkpoints, and retained history health. No permanent-delete path is introduced. Use Vault Health for manifest/journal/post-action detail.

Provenance without raw-log retention

Typed System Evidence

This journal keeps compact typed summaries/signals only. Raw Terminal output remains visible in System Console for the current query but is not copied into this retained journal.
