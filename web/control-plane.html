Security Posture

Explicit capture

System Snapshot & Diff

Captures selected current processes, launch services, TCP state, mounts/filesystems, and core security posture. Retention is bounded; it is not a complete audit log.

Growth attribution

Storage History

Captures the latest completed Storage Intelligence result into the existing bounded storage-history model. Run a storage scan in Sentinel first when no completed result is available.

Recover

Recovery Center 2.0

Aggregates Sentinel-owned Safe Actions, Vault, action journal, Change Monitor checkpoints, and retained history health. No permanent-delete path is introduced.

Provenance without raw-log retention

Typed System Evidence

This journal keeps compact typed summaries/signals only. Raw Terminal output remains visible in System Console for the current query but is not copied into this retained journal.
