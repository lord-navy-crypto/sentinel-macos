What these fields mean

Model IdentifierApple's technical model family identifier. It is useful when checking macOS and hardware compatibility.
Chip / ProcessorThe main CPU or Apple system-on-chip. Apple M-series chips are Apple Silicon; older Macs may use Intel processors.
Architecturearm64 means Apple Silicon native code. x86_64 means Intel code. Sentinel's Universal desktop app chooses the matching engine automatically.
Physical vs logical coresPhysical cores are actual CPU cores. Logical cores can include additional execution threads exposed by the processor.
Performance / efficiency coresSome Apple Silicon chips mix high-performance and energy-efficient CPU cores. If macOS does not expose the split, Sentinel leaves it blank rather than guessing.
MemoryTotal memory visible to macOS. On Apple Silicon this is unified memory shared efficiently by CPU and GPU workloads.
macOS buildThe detailed Apple build identifier for the installed macOS version, useful when troubleshooting exact system revisions.
Rosetta translationIf enabled, an Intel executable is currently being translated on Apple Silicon. Native arm64 execution is preferable when available.

Hardware privacy

System Profile is read-only and local. Sentinel does not need a serial number or Hardware UUID to explain compatibility, so those unique identifiers are deliberately excluded from this page and from low-sensitivity diagnostics.

What these actions mean

RenameChanges the filename in the same directory. It can break path-based references, but is not a security boundary and does not stop a running process.

Sentinel VaultMoves an eligible file into a private Sentinel recovery directory, stores a manifest, and removes executable permission bits from the stored copy.

RestoreReturns a Vault item to its recorded original path and permissions only if that path is still empty.

Reveal in FinderLets you inspect the object yourself before deciding.

Quick Start

1. OverviewCheck whether required macOS evidence sources are available.
2. StorageFind where space went; duplicate and version-family results are review aids, not deletion orders.
3. Security & IntegrityUse Security Audit for correlation; use Integrity Lab when you want deep evidence for one path.
4. PersistenceReview Startup/Login Items, then capture Persistence Integrity to notice configuration changes during this session.
5. Behavior & TrustBehavior compares adjacent states. Trust compares against a profile you explicitly approved.
6. Safe ActionsFor eligible user-home files, preview dependencies first; then use Rename or Sentinel Vault. Permanent deletion does not exist.

Permissions

Normal accessEnough for many process, disk, signature, and startup checks.

Full Disk AccessSome protected locations require explicit user approval in System Settings. Sentinel should degrade visibility when access is denied.

Endpoint SecurityTrue system-event streaming requires Apple’s Endpoint Security entitlement and a System Extension. V2.2 includes an entitlement-gated notification-sensor scaffold but does not claim it is installed or enabled.

How to read results

Risk scoreHeuristic review priority, not malware probability.

Verified signatureShows signed code validates; it does not guarantee good intent.

Gatekeeper acceptedUseful macOS trust context, still not a malware verdict.

Trusted Profile matchMeans “matches the reference you approved,” not “safe forever.”

Authoritative design basis

The V2.2 architecture is aligned to Apple documentation rather than treating all system evidence as equivalent.

Code Signing ServicesSignature and signed-code validation context.
Gatekeeper & NotarizationDistribution/trust context, not a malware probability.
ServiceManagement / SMAppServiceModern Login Item, LaunchAgent, and LaunchDaemon model.
Full Disk AccessUser-controlled visibility boundary; Sentinel cannot grant it to itself.
FSEventsV2.2 Change Monitor uses native CoreServices FSEvents when compiled on macOS, with checkpoint/resume and an explicitly labeled polling fallback otherwise.
Endpoint Security + System ExtensionsOptional entitlement-gated notification sensor scaffold. The normal release does not claim an installed System Extension.
