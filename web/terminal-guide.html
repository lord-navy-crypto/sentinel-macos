01 · Start

How to use the page / 如何开始使用

English

Start from Ask the Mac when you have a question, or use Terminal Toolbox when you already know the evidence domain. The search box filters the fixed tool catalog; it does not turn your text into a shell command.

  1. Choose a question or tool.
  2. If the tool needs a target, enter the requested PID or absolute path.
  3. Run it once and read the structured result first.
  4. Open Raw Evidence when you need the underlying terminal output.
  5. Use Continue Investigation only when an object needs deeper correlation.

中文

如果你先有一个问题，就从 Ask the Mac 开始；如果你已经知道要查看哪类证据，就使用 Terminal Toolbox。搜索框只用于筛选固定工具，不会把输入内容变成 shell 命令。

  1. 选择一个问题或工具。
  2. 如果工具需要目标，输入要求的 PID 或绝对路径。
  3. 运行一次，优先阅读结构化结果。
  4. 需要底层命令输出时再展开 Raw Evidence。
  5. 只有当某个对象值得继续关联时，再使用 Continue Investigation。

02 · Inputs

PID, path and fixed commands / PID、路径与固定命令

English

PID means a currently running process identifier. It can become stale after a process exits or restarts. Absolute path means a macOS path beginning with /, for example /Applications/Safari.app. The command preview shows the fixed executable and arguments Sentinel intends to run. Placeholders such as <PID> or <absolute-path> indicate the only variable target.

中文

PID 是当前正在运行的进程编号；进程退出或重启后，旧 PID 可能失效。绝对路径是以 / 开头的 macOS 路径，例如 /Applications/Safari.app。命令预览会显示 Sentinel 准备执行的固定程序和固定参数；<PID> 或 <absolute-path> 这样的占位符表示唯一允许变化的目标。

04 · Output

How to read a result / 如何阅读结果

English

Read in layers: Summary → Structured evidence → Raw evidence → Limitations. Summary answers what was observed. Structured evidence separates fields and records. Raw Evidence preserves the terminal output. Limitations explain permission errors, missing visibility or bounded output. A missing observation is not proof that nothing exists.

中文

建议按照 摘要 → 结构化证据 → 原始证据 → 限制 的顺序阅读。摘要说明观察到了什么；结构化证据拆分字段和记录；Raw Evidence 保留底层终端输出；Limitations 说明权限错误、可见性缺口或输出边界。没有观察到某项内容，并不等于它一定不存在。

05 · Continue Investigation

When to branch deeper / 什么时候继续调查

English

Continue Investigation takes a concrete file/app/process-related object and opens the investigation workspace. That workspace correlates bounded file evidence with identity, runtime, persistence, network and Object Story context. Only one branch should run at a time; while a branch is active, other continuation controls are temporarily locked to avoid overlapping scans.

Use it when the Terminal result gives you a specific object worth understanding. Do not use it as a substitute for scanning the entire disk.

中文

Continue Investigation 会把一个明确的文件、应用或进程相关对象送入调查工作区，并在有界范围内关联文件证据、身份、运行时、持久化、网络以及 Object Story。一次只运行一个调查分支；当前分支运行期间，其他继续调查按钮会暂时锁定，避免多个扫描互相堆叠。

当 Terminal 结果里出现一个具体且值得理解的对象时使用它；不要把它当作全盘扫描的替代品。

07 · Problems

If a tool looks stuck or empty / 如果工具卡住或没有结果

English

  • Check whether Sentinel still has a valid local session token.
  • For PID tools, confirm the process still exists; PIDs are temporary.
  • For path tools, use an absolute path and confirm the object still exists.
  • Permission errors are visibility gaps; grant only permissions you intentionally want Sentinel to have.
  • For a long investigation, wait for the active branch to finish instead of repeatedly clicking Continue.
  • Use Raw Evidence and Limitations to distinguish “no result” from “could not observe”.

中文

  • 确认 Sentinel 当前本地 session token 仍然有效。
  • PID 工具要确认进程仍然存在；PID 是临时的。
  • 路径工具要使用绝对路径，并确认对象没有被移动或删除。
  • 权限错误属于可见性缺口；只授予你明确愿意给 Sentinel 的权限。
  • 长调查运行时等待当前分支结束，不要连续重复点击 Continue。
  • 通过 Raw Evidence 和 Limitations 区分“确实没有结果”和“无法观察”。

Sentinel Terminal is a bounded evidence interface. It does not provide arbitrary shell execution, permanent delete, or a malware probability certificate. / Sentinel Terminal 是有边界的证据界面，不提供任意 shell、永久删除，也不会输出所谓恶意软件概率证书。
