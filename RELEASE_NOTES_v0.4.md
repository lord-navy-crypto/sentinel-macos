# Sentinel macOS v0.4 — Identity & Lineage

v0.4 strengthens the correlation model introduced in v0.3.

Highlights:
- macOS Code Identity: Identifier, Team ID, signing authorities, app bundle, Gatekeeper context
- bounded parent-process lineage
- structured TCP endpoint classification
- modern Login & Background Items read-only snapshot
- Terminal Evidence Sources transparency panel
- richer Process Evidence and Object Story
- Background Task Management data included in local report export

Safety remains unchanged: localhost-only, session-token protected, no destructive system endpoints, no daemon, no cloud requirement.
